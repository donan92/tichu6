# 2026-11-24 봇 연구 결과와 적용 결정

## 결론

기본 봇에는 검증된 규칙 후보 gentle(structureWeight=15)를 반영한다.
신경망은 연구 산출물로 보존하며 운영 경로에 넣지 않는다. LLM은 설계·전략 검토에
활용했으며, 매 턴 외부 API 호출이나 LLM 파인튜닝은 도입하지 않았다.
모든 상대에게 최적이라는 결과가 아니다. 상대에 따라 순위가 바뀌며 사람과의 협력은 미검증이다.

## 해석과 한계

- E0(REINFORCE)는74,613번 실제 가중치를 업데이트했다. 기본 봇과 혼합 팀에는 개선이
  있었지만 gentle와 선언 상대에는 평균 점수가 낮았다. 완성형 강한 모델로 보지 않는다.
- DMC는53,249개 파라미터,221특징, 세 초기값으로5,061/5,061/5,060회 학습했다.
  모두 초기 가중치와 최종 가중치가 다르지만 이번 파일럿의 성적은 낮았다.
- E0는10,305개 파라미터/한 초기값/16짝 검증, DMC는32짝 검증이다. 검증 선택 편향이
  남는다. DMC는 늦게 시작해 학습 예산도 작아, 알고리즘 자체의 공정한 우열 비교가 아니다.
- gentle 한 명+기존 봇 둘은 +2.205점이지만 구간이0을 포함한다. 이 구성의 개선은 불확실하다.
  둘/셋일 때는 점수 개선이 관측됐다. 실제 사람 팀원에 대한 성능은 별도 확인해야 한다.
- 기준 봇은 티츄 선언을 하지 않는다. 별도 선언 상대는 임계값5.5/7의 규칙 후보이며
  강한 사람이나 최적 전략을 대표하지 않는다. 선언 효과만 분리한 실험도 아니다.
- 신경망은 내기·패스만 학습하고 나머지 단계는 기존 정책에 의존한다. 합법 수 후보도
  대표 조합이므로 모든 문양 조합, 순서 밖 폭탄, 전체 단계 학습을 완성한 상태가 아니다.
- 최종 평가 결과를 모델 가중치나 계수 수정에 사용하지 않았다. 후속 실험에는 새로운
  봉인 평가 namespace를 사용해야 한다.

## 반영 내용과 운영 상태

- src/bot-structure.js의 고정 gentle 점수 함수를 src/game.js:botAction에서 사용한다.
  서버와 연습 게임이 같은 엔진을 사용한다. 후보별 점수는 한 번만 계산하고 동점 순서를 보존한다.
- 교환/선언/트릭 전달과 의무 소원/완주/팀원 보호/폭탄 사용 조건은 기존 엔진 경계를 유지한다.
- 실제 행동과 연구 후보의 전체 라운드 대조, 비공개 패 변조 불변, 의무 소원과 종료 테스트를 수행한다.
- 기록된 오프라인 봇 대행 정책 버전은 structure-gentle-v1이다. 사람 기록은 동의 기본값off,
  비공개 보관이며 익명 매치 단위로 데이터셋을 분리한다. 실제 사람 데이터로 학습하지 않았다.
- 로컬 변경이며 커밋·머지·배포하지 않았다. 운영 봇이 바뀌었다고 주장하지 않는다.
