# 모델 적합성과 LLM 적용 판단

2026-11-24. 사용자 요청: 현재 모델이 적절한지 분석하고, LLM이 도움이 된다면 적용.

## 결정

게임의 기본 플레이어는 **작은 전용 강화학습 모델**을 우선한다. 현재 REINFORCE 모델을
비교군으로 보존하고, 문양·공개 이력을 포함하는 DMC 모델을 별도로 구현·검증한다.
LLM을 매 턴 호출하는 운영 구조나 LLM 파인튜닝은 지금 채택하지 않는다. LLM은 현재처럼
설계·전략 검토와 오류 분석에 사용한다. LLM의 제안을 학습 정답이나 게임 실력으로
간주하지 않고 엔진과 독립 대결로 검증한다.

이 결정은 6인 티츄에서 DMC가 모든 LLM보다 강하다는 실험 결과가 아니다. 현재 자원,
무료 운영, 합법 수가 명확한 게임 구조와 검증된 정보에 따른 우선순위다.

## 현재 모델 평가

E0는62→64→64→32→1,10,305개 파라미터의 TensorFlow.js 신경망이다. 실제 종료 보상으로
가중치가 갱신되고 체크포인트가 저장된다. 딥러닝 실험의 기준 모델로는 적절하지만,
최종 게임 모델로 삼기에는 다음 제한이 크다.

- 랭크 위주 입력이어서 문양별 스트레이트 폭탄과 보존 전략을 충분히 구분하지 못한다.
- 공개 이력과 선언·교환·전달 판단을 직접 학습하지 않는다.
- REINFORCE의 단일 라운드 결과에 의존하며 보상을±1로 잘라 큰 점수 차이를 잃는다.
- 한 번의 초기화와16쌍 개발 검증으로는 일반화 성능을 입증할 수 없다.

학습 라운드가 많다는 사실은 위 구조적 한계를 없애지 않는다. 현재 실험 조건은 중간에
바꾸지 않고 E0로 남긴다.

## 문헌에서 확인한 근거

- [DouZero, ICML2021](https://proceedings.mlr.press/v139/zha21a.html):
  합법적인 카드 행동을 인코딩하고 실제 대국 결과를 신경망으로 회귀하는 DMC를 사용한다.
  가변 조합을 평가하는 구조의 참고이며 두지주 결과를6인 티츄 성능으로 옮겨 주장하지 않는다.
- [Sparks of Cooperative Reasoning, ICML2026](https://proceedings.mlr.press/v306/ramesh26a.html):
  LLM의 하네비 협력 성능과 게임별 추가 학습의 효과를 보여준다. 다만 상태 추적의
  신뢰성 문제가 남는다. [원문 부록](https://arxiv.org/html/2601.18077v2)의 RL 학습은
  8×A100을 사용했으며, 우리의 로컬 CPU 실험과 자원 규모가 다르다.
- [PokerBench, AAAI2025](https://arxiv.org/html/2501.08328v1):
  게임별 튜닝이 도움이 되지만 정답 행동 적합도와 실제 상대전 성적이 일치하지 않을 수
  있음을 보여준다. LLM이 설명을 잘하거나 모방 정확도가 높다는 이유로 채택하지 않는다.
- [A Generalist Hanabi Agent, ICLR2025](https://research.ibm.com/publications/a-generalist-hanabi-agent):
  낯선 팀원·다른 설정에 대한 협력을 별도로 다루는 강화학습 연구다. 파트너 다양성은
  언어 모델 사용 여부와 별개로 평가해야 한다.

## 적용할 개선과 통과 기준

1. 별도 `research/dmc/` 실험에서 문양별 내 패·남은 패와 공개 이력 요약을 입력한다.
2. DMC MSE 목표는 실제 팀 점수 차이/1000이며 clipping하지 않는다.
3. 세 독립 초기값/난수 흐름으로 학습하고 각자의 검증 최고 모델을 보존한다.
4. 기존2시간 실험은 보존한다. 새 실험은 동일 종료 시각 안의 남은 예산을 사용하며,
   학습량이 다른 실험을 동등한 계산 예산 비교라고 부르지 않는다.
5. 아직 교환·선언·순서 밖 폭탄·GRU·완전한 문양별 합법 수 열거까지 끝난 정식 모델은
   아니다. 이 단계는 입력·목표함수 개선을 검증하는 후속 파일럿이다.
6. 기존 봇/선정 규칙 후보/선언하는 상대/혼합 팀에서 새로운 패로 검증한 뒤 채택 여부를
   결정한다. 독립 학습 간 결과 차이도 보고한다. 운영 추론도 다시 측정한다.

LLM 교사를 더 확장할 경우에는 합성 대국의 관측과 합법 행동 목록만 제공하고,
제안 행동을 실제 대국으로 평가한 뒤 전용 모델에 증류한다. LLM 추천을 보상에 그대로
더하거나 최종 평가 패를 프롬프트 예시로 사용하지 않는다. 현재는 그런 라벨 학습을
실행했다고 주장하지 않는다.

## 이번 파일럿의 학습 확인과 다음 실험

E0는74,613회, DMC 세 초기값은 각각5,061/5,061/5,060회 gradient update를 수행했다.
초기·최종 가중치 해시가 달라 실제 학습이 일어났음을 확인했다. DMC의32쌍 개발 검증
최고 평균 점수 차이는-62.66/-99.53/-80.63이다. 이 수치는 최종 평가 결과가 아니며,
새 모델을 운영 봇으로 교체할 근거가 되지 않는다. E0와 계산 예산도 다르다.

DMC는 무작위 초기 행동에서 시작했고, 선택된 행동에 라운드 종료 점수만 회귀한다.
따라서 약한 초기 정책, 거친 보상 배분, 부족한 학습 예산, 대표 행동 후보의 누락이
실패 원인일 수 있다. 현재 결과로 어느 하나를 확정하지 않는다.

다음 원인 분리 실험은 **무작위 초기화 DMC 대 규칙 봇 모방 사전학습 후 DMC**다.
같은 세 초기값·패·상대 풀·신경망·후속 강화학습 업데이트 수로 비교하며, 모방 학습에
쓴 추가 계산량도 별도 보고한다. 개발 검증을 최소256쌍으로 늘리고 최종1,000쌍은
새 namespace로 봉인한다. 이번 최종 평가 패는 다시 모델 선택에 사용하지 않는다.
모방 사전학습이 개선되지 않아도 다른 원인이 입증되는 것은 아니다. 행동 후보와 보상
배분을 각각 분리한 후속 실험이 필요하다. 이 비교 실험은 아직 실행하지 않았다.
